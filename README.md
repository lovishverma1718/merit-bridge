# Merit Bridge Solutions Inc. — Website

Five-page static marketing website for Merit Bridge Solutions Inc., a business process outsourcing company.

## Pages

| Page | File |
| --- | --- |
| Home | `index.html` |
| Services | `services.html` |
| About | `about.html` |
| Why Us | `why-us.html` |
| Contact | `contact.html` |

Styles live in `assets/css/styles.css`, interactions in `assets/js/main.js`.

## Run locally

```bash
python -m http.server 5510
```

Then open http://localhost:5510.

## Notes

- Photography is loaded from Unsplash (free commercial licence). Consider downloading the images into `assets/img/` before launch.
- The contact form opens the visitor's email client with a pre-filled message to admin@meritbridgesolution.com.
